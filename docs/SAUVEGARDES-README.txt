DOSSIER DE SAUVEGARDES

Enregistrez ici les copies créées depuis:
Paramètres > Sauvegarde des données.

Bonnes habitudes:
- l'application crée automatiquement une copie chaque jour sur l'ordinateur;
- faites aussi une copie sur cette clé au moins une fois par semaine;
- gardez une deuxième copie sur une autre clé USB;
- écrivez la date dans le nom de la copie;
- pour récupérer une copie, utilisez la fonction de restauration de l'application.
