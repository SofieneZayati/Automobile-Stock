BEN MAHMOUD STOCK — GUIDE RAPIDE

OUVRIR L'APPLICATION
- Double-cliquez sur "Ben-Mahmoud-Stock-Portable.exe".
- Aucun navigateur, serveur, Node.js ou terminal n'est nécessaire.
- La base de données est créée automatiquement au premier lancement.
- Les données sont conservées sur le PC du magasin, pas dans l'EXE.

PREMIÈRE CONFIGURATION
Ouvrez "Paramètres" et renseignez/vérifiez:
- nom et activité de l'établissement;
- adresse et téléphones;
- matricule fiscal;
- TVA par défaut;
- préfixe et format des numéros de facture.

SAISIR LE STOCK
1. Ajoutez d'abord les fournisseurs utiles dans "Fournisseurs".
2. Ouvrez "Pièces & stock" puis "Ajouter une pièce".
3. Pour chaque pièce, saisissez:
   - référence;
   - désignation;
   - référence OEM si disponible;
   - compatibilité véhicule;
   - catégorie;
   - fournisseur;
   - prix d'achat;
   - prix de vente;
   - quantité actuelle;
   - seuil de stock faible;
   - emplacement/rayon.
4. Pour les réapprovisionnements suivants, utilisez "Ajuster le stock" au lieu de modifier la quantité manuellement.

CLIENTS
- Les clients réguliers peuvent être enregistrés dans "Clients".
- Pour une vente simple, "Client comptoir" peut être utilisé sans créer de fiche client.

FACTURES
- Ajoutez les pièces depuis le stock réel.
- Le prix client peut être négocié avant validation.
- Le total final peut aussi être arrondi commercialement.
- Un brouillon peut être enregistré puis rouvert plus tard.
- Le numéro définitif est attribué uniquement lors de la validation.
- Une facture peut être imprimée ou enregistrée en PDF.

SAUVEGARDE
Dans "Paramètres > Sauvegarde des données":
- créez régulièrement une sauvegarde;
- enregistrez une copie sur une clé USB ou un disque externe;
- la restauration vérifie le fichier avant de remplacer les données actives.

MISE À JOUR
- Fermez l'application.
- Remplacez uniquement l'ancien EXE par le nouvel EXE.
- La base de données du magasin n'est pas stockée dans l'EXE, donc une mise à jour normale ne supprime pas le stock ni l'historique.
